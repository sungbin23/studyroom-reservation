## 4. 계층적 작업분석(HTA)
> **대표 과업:** 모바일에서 4명이 쓸 수 있는 다음 주 수요일 오후 2시 빈 방을 예약한다.

| 번호 | 목표·하위 작업 | 선행 조건 | 정보·도구 | 오류·예외 |
|---|---|---|---|---|
| **0** | **최종 목표: 빈 스터디룸 예약 완료** | 모바일 브라우저 접속 | 학번, 비밀번호 | 로그아웃 상태일 시 로그인 창 이동 |
| 1 | 날짜 및 조건 설정 | - | 인원수, 달력 | - |
| 1.1 | 인원수(4명) 선택 | 앱 접속 완료 | 터치 버튼 | - |
| 1.2 | 날짜 및 시간 선택 | 인원수 입력 완료 | 달력 컴포넌트 | 과거 날짜 선택 불가 |
| 2 | 빈 방 리스트 확인 및 선택 | 1번 완료 | 빈 방 리스트 | 원하는 시간에 빈 방이 없음 (예외) |
| 2.1 | [예외 처리] 추천된 인접 시간대 방 선택 | 2번에서 빈 방 없음 | 인접 시간 목록 | - |
| 3 | 최종 예약 확정 및 QR코드 확인 | 방 선택 완료 | 확인 버튼 | 네트워크 지연으로 승인 실패 |

> **실행 계획:** 1 (1.1 → 1.2) → 2 → 3. 빈 방이 없으면 2.1 후 3으로 진행.
